# Ghost

**Ghost voit ce que vous répétez, et le fait à votre place.** Vous cliquez sur « Observer » et travaillez normalement : Ghost repère la tâche répétée, la transforme en agent H (H Company), puis la fait à votre place sur des sites sans API, avec une preuve vérifiée à chaque fois.

Projet d'Alejandro Mendoza Hermida, né pendant le hackathon « Build The Future » (Eugenia × H Company, 16 au 20 novembre 2026). En cours de construction.

## Contenu actuel

| Dossier | Contenu |
|---|---|
| `portails/` | Trois sites d'annonces de test sans API (Portail A, B, C), avec une API de lecture pour la vérification |
| `donnees/` | Données fictives de l'Agence Belvédère : mandats et photos |
| `reference/agent-h-v1/` | Première version de l'agent H en Python (consignes, contrôle des pièges, vérification sur les portails), à porter dans la nouvelle application |
| `supabase/` | Schéma de la première version, pour référence |
